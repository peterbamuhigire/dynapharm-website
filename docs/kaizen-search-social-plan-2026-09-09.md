## Search and AI implementation

Keep city names in visible DPC cards, matching FAQs and readable Markdown. Use the same source document for HTML and Markdown. Keep canonical URLs, bilingual alternates and sitemap entries aligned. Structured data lists the client-confirmed cities without invented street addresses or local phone numbers.

The optional /llms.txt index supports content retrieval. It is not a ranking guarantee. Google's current guidance keeps standard SEO fundamentals relevant to AI features and does not require special AI files: https://developers.google.com/search/docs/appearance/ai-features (opened 9 September 2026).

## Measurement and ownership

Use utm_source for the publishing platform, utm_medium=social and utm_campaign=senegal_dpc_profile. Keep UTM parameters off canonical URLs. The analytics owner should record profile visits and catalogue clicks as separate measures; no performance uplift is claimed without data.

The content owner maintains the locations and copy; the SEO owner checks metadata and indexing; the social owner approves and publishes drafts; the build owner runs build, link and responsive checks. Revert only the affected component or content changes if a regression appears.
